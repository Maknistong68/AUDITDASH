# Project skills

Claude Code loads every folder here automatically when working in this repo.

| Skill | What it does | Source | License |
|---|---|---|---|
| `design-taste-frontend` | "Taste Skill": art direction for landing pages and app screens, with scripts that deal design directions and inspect the result in a real browser | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | MIT |
| `web-design-guidelines` | Reviews UI code against Vercel's Web Interface Guidelines (accessibility, UX, performance) | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) | MIT |
| `awesome-design-md` | 80+ DESIGN.md references (Stripe, Linear, Vercel, ...) to base a design system on | [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) | MIT |
| `image-to-code` | Generates design images first, then implements the site to match them | [Leonxlnx/imagegen-skills](https://github.com/Leonxlnx/imagegen-skills) | MIT |
| `screenshot-to-code` | Turns a screenshot or mockup into React/Tailwind/HTML and compares the render to the image | [onewave-ai/claude-skills](https://github.com/onewave-ai/claude-skills) | MIT |
| `playwright-cli` | Drives a real browser from the command line: open pages, click, screenshot, test | [microsoft/playwright-cli](https://github.com/microsoft/playwright-cli) | Apache-2.0 |

`playwright-cli` needs the `@playwright/cli` npm package (`npm install -g @playwright/cli@latest`).
To update a skill, re-copy its folder from the source repo.
